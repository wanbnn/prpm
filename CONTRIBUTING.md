# Contribuindo com o PRPM

Obrigado por contribuir.

1. Crie um fork e uma branch curta.
2. Instale o projeto com `python -m pip install -e ".[dev]"`.
3. Faça mudanças pequenas e inclua testes.
4. Execute `python -m pytest`.
5. Abra um pull request explicando o problema e a solução.

Não inclua credenciais, ambientes virtuais ou artefatos de build nos commits.
